# 小乖 × LINE／Telegram 設定教學

完成後你可以：

- 在 LINE 或 Telegram 上直接跟小乖聊天，叫它幫你記待辦、排行程、設提醒、寫筆記
- 提醒時間到，小乖會用 LINE／Telegram 通知你（每 5 分鐘檢查一次）
- LINE、Telegram 和網頁版（Assistant.html）看到的是同一份資料，資料存在你自己的 Google 試算表

LINE 和 Telegram 可以兩個都接，也可以只接一個。只要 Telegram 的話，跳過第 1 步和第 4 步，做第 2、3、5 步（要接網頁版再做第 6 步）。整個流程大約 15 分鐘，只需要做一次。

## 1. 建立 LINE 官方帳號與 Messaging API

1. 到 [LINE Developers](https://developers.line.biz/console/) 用你的 LINE 帳號登入。
2. 建立 Provider（名字隨意，例如「彥彬」）。
3. 在 Provider 下建立 **Messaging API** 頻道，這一步會同時建立小乖專屬的新 LINE 官方帳號（名稱可以取「小乖」）。請不要用店裡（莫凡）的官方帳號，避免客人的訊息跑進小乖。
4. 進入頻道的「Messaging API」分頁，最下方的 **Channel access token** 按「Issue」，複製起來備用。
5. 到 LINE Official Account Manager 的「回應設定」：
   - 關閉「自動回應訊息」
   - 開啟「Webhook」

## 2. 建立 Google 試算表與 Apps Script

1. 到 Google 試算表新建一份空白試算表，命名為「小乖資料庫」。
2. 選單「擴充功能 → Apps Script」。
3. 把編輯器裡的 `Code.gs` 內容全部刪掉，貼上本資料夾的 [Code.gs](Code.gs)，按儲存。
4. 左側齒輪「專案設定」：
   - 勾選「在編輯器中顯示 appsscript.json」，回到編輯器，把 `appsscript.json` 換成本資料夾的 [appsscript.json](appsscript.json)（主要是把時區設成台北）。
   - 往下找到「指令碼屬性」，新增兩個：

     | 屬性 | 值 |
     | --- | --- |
     | `OPENAI_API_KEY` | 你的 OpenAI 金鑰（`sk-` 開頭） |
     | `LINE_CHANNEL_ACCESS_TOKEN` | 第 1 步複製的 Channel access token（只用 Telegram 可不填） |

5. 回到編輯器，上方函式選單選 `setup`，按「執行」。第一次會要求授權，依畫面允許即可。
6. 執行完看「執行記錄」，會出現 **同步密碼**，抄下來。試算表裡也會多出「待辦、行程、提醒、筆記…」幾個分頁。

## 3. 部署成網頁應用程式

1. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**所有人**。
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

之後如果改了程式，要用「部署 → 管理部署作業 → 編輯 → 版本選新版本」更新，網址才不會變。

## 4. 接上 LINE

1. 回到 LINE Developers 的「Messaging API」分頁，Webhook URL 填：

   ```
   https://script.google.com/macros/s/…/exec?key=你的同步密碼
   ```

2. 開啟「Use webhook」。
3. 用手機掃頁面上的 QR code 加小乖好友，傳：

   ```
   綁定 你的同步密碼
   ```

   看到「綁定完成」就可以開始聊天了。綁定後只有你能使用，別人加好友也不會回應。

> 按 Webhook 旁的「Verify」可能會顯示失敗，這是因為 Apps Script 會先轉址一次。只要實際傳訊息小乖有回，就是正常的。

## 5. 接上 Telegram

1. 在 Telegram 搜尋 **@BotFather**，傳 `/newbot`，依指示取名字（例如「小乖」）和帳號名稱（要以 `bot` 結尾，例如 `xiaoguai_yb_bot`）。
2. BotFather 會回你一串 **token**（像 `123456789:ABC…`），複製起來。
3. 回到 Apps Script「專案設定 → 指令碼屬性」，新增兩個：

   | 屬性 | 值 |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | BotFather 給的 token |
   | `WEBAPP_URL` | 第 3 步的網頁應用程式網址（結尾是 `/exec`） |

4. 回到編輯器，函式選單選 `setupTelegram`，按「執行」。執行記錄出現 `"ok":true` 就接好了。
5. 在 Telegram 打開你的機器人，按「開始」，再傳：

   ```
   綁定 你的同步密碼
   ```

   看到「綁定完成」就可以聊天了。綁定後只有你能使用。

## 6. 接上網頁版

打開 Assistant.html → 設定 → 「LINE 與雲端同步」，貼上第 3 步的網址和同步密碼，按「儲存並立即同步」。看到「上次同步：…」就完成了。

網頁開著時每分鐘自動同步一次，切回分頁、新增或修改資料時也會同步。換手機或換瀏覽器，只要填同樣的網址和密碼，資料就會跟過來。

## 7. 剪片：🎬 剪 Reels／🎞️ 剪大片（自動剪輯、字幕、動畫字卡、配樂）

兩種剪法（2026-10-16）：
- **🎬 剪 Reels**：挑精華剪成直式 9:16 短影音（最長 60 秒，說明可寫秒數），中英短句字幕。
- **🎞️ 剪大片**：保留整支影片的內容和原本的橫直，只剪掉停頓、口誤和重複，上中文字幕（說明寫「中英字幕」就加英文）。影片較長時畫質會自動調低，才傳得回 Telegram（50MB 上限）。按「🎞️ 剪大片」再傳影片，或影片說明寫「剪大片」。

**好幾支影片一起剪（2026-10-16）：** 按「🎬 剪 Reels」或「🎞️ 剪大片」後，可以一次選好幾支影片傳（最多 10 支，每支 20MB 以內），小乖每收到一支會回「收到第 N 支」；傳完按「✂️ 開始剪」，就照傳的順序接起來剪成一支。傳錯了按「🗑️ 重選影片」重來。只有一支也是傳完按「✂️ 開始剪」。

**兩種剪法：🎤 口播剪／🎵 靜音剪（2026-10-16）：** 影片傳完會出現兩個按鈕：
- **🎤 口播剪**：影片裡有人講話。剪掉停頓和口誤、上字幕、段落之間推近／拉遠鏡頭（跳剪）、重點字卡跳出來、上方進度條。
- **🎵 靜音剪**：沒有講話的畫面（產品、活動、風景）。跟著配樂節拍切段、每段有運鏡（推近、拉遠、平移）、段落之間有轉場特效（閃白、滑動、放大、圓形展開…）和「咻」的音效、畫面字幕一句一句彈出來（重點詞亮色）、結尾行動呼籲、上方進度條。預設約 20 秒，說明寫秒數就照秒數。
- 按「✂️ 開始剪」由小乖自己判斷有沒有人講話。影片說明寫「靜音」或「口播」也可以。
- 不想要特效：說明或修改時寫「不要特效」；不要進度條：寫「不要進度條」。

**英文字幕、字幕特效、音效（2026-10-16 晚）：**
- 每種剪法都上中英字幕（大片原本只有中文，現在也加英文；說明寫「只要中文」就只上中文）。靜音剪的畫面字幕也有英文。
- 字幕特效：每句彈一下跳出來、後面一層柔光更立體，重點詞換亮色（口播由 AI 標、靜音剪每句一個）。
- 配樂：每首先校成一樣大聲、開頭淡入，有人講話時自動壓低、講完慢慢回來。
- 音效（Kenney CC0 真實錄音，放在 `reels/sfx/`）：標題打字聲、標籤打勾和字卡「啵」、重點字卡和結尾「叮」、字幕滑入「咻」、轉場「咻」。不要音效：說明寫「不要音效」。

**配樂（2026-10-16 改成真人演奏）：** `reels/music/` 放的是 Kevin MacLeod（incompetech.com）的真人演奏配樂，授權 CC BY 4.0，可以商用，但貼文要保留署名；小乖送來的貼文文案最後會自動附上署名（`reels/music/credits.json`）。AI 會依影片氣氛挑一首；說明寫曲名的前兩個字也可以指定。想用自己的音樂：按剪片按鈕後先傳一首音樂檔（或音樂說明寫「配樂」），之後剪的影片都用那首；打「配樂預設」換回小乖挑的。自己的音樂請用有權使用的，發到社群才不會被檢舉。

**字幕檢查：** 剪好後程式會比對有字幕和沒字幕的畫面，確認字幕真的畫上去；GitHub 紀錄會寫「字幕檢查：畫面差異 …」，太小會標 ⚠️。也會先確認中文字型有裝好，找不到就換一個繁中字型。

在 Telegram 按「🎬 剪 Reels」再傳影片（或傳影片時說明寫「剪 Reels」），小乖會自動挑精華、剪掉講話中間的停頓，剪成直式 9:16、上中英短句字幕和動畫字卡（開頭標題一個字一個字打出來、重點標籤一個個打勾、重點句跳出字卡）、配背景音樂，大約 3～6 分鐘把「第 1 版試剪」傳回 Telegram，還附一段貼文文案。

- **要改**：長按小乖傳回的影片按「回覆」，直接說要改哪裡（例如「字幕大一點」「開頭標題久一點」「剪成 30 秒」「不要動畫」），小乖就剪下一版。也可以打「改影片 …」。
- **學風格**：看到喜歡的影片就截圖傳給小乖，說明寫「我要這種風格」，小乖會記下字幕顏色、大小、位置和強調色，之後都照這個剪；按「🔁 用這個風格重剪」可以把上一支重剪。打「Reels 風格預設」換回原本的。剪輯在 GitHub Actions 上跑（程式在 `reels/reels.py`），公開的 repo 不用錢。

只要設定一次，一步一步來：

1. **GitHub 放兩把鑰匙**：手機瀏覽器打開 <https://github.com/yb131419/Tezhu/settings/secrets/actions> → 按「New repository secret」，新增兩個：

   | Name | Secret |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | 跟 Apps Script 指令碼屬性裡的同一串 |
   | `OPENAI_API_KEY` | 跟 Apps Script 指令碼屬性裡的同一串 |

2. **做一把讓小乖叫 GitHub 剪片的金鑰**：打開 <https://github.com/settings/personal-access-tokens/new>
   - Token name 填「小乖剪 Reels」，Expiration 選「No expiration」（或一年）
   - Repository access 選「Only select repositories」→ 選 `yb131419/Tezhu`
   - Permissions → Repository permissions → **Actions** 改成「Read and write」
   - 按「Generate token」，複製那串 `github_pat_…`
3. **把金鑰交給小乖**：在 Telegram 傳 `設定 GitHub金鑰 github_pat_…`。小乖存好後會自動刪掉那則訊息。
4. **更新 Apps Script**：把新的 `Code.gs` 貼進去 → 部署 →「管理部署作業」→ 編輯「助理小乖007」→ 版本選「新版本」→ 部署（不要「新增部署作業」，網址會變）。

說明可以加的要求：`30秒`、`標題：邀約三招`、`只要中文字幕`、`中英字幕`、`不要字幕`、`不要配樂`、配樂曲名。沒寫就照預設（Reels 最長 60 秒、中英字幕；大片不限長度、中文字幕），配樂依影片氣氛挑。

- 影片要在 20MB 以內：Telegram 傳影片時選「壓縮」（不要用檔案傳）就好。
- 想長期加配樂：把 mp3 放進 `reels/music/`，檔名就是曲名；需要署名的話寫進 `credits.json`。
- 剪片紀錄在 GitHub 的「Actions → 小乖剪 Reels」看得到；repo 是公開的，所以紀錄裡只寫秒數和段數，不會寫字幕內容。

## 8. 📤 發社群：IG、Threads、FB 粉專（Meta 官方 API，免費、不用第三方）

小乖直接把智囊軍師的圖卡（3 張或 7 張輪播）、剪好的 Reels、你自己的照片或影片發到 IG、Threads、FB 粉專。每次都先給你看預覽，按「✅ 全部發」或「只發 IG／Threads／FB」才會發出去。三個平台可以只設定其中幾個，有設定的才會出現。

**設定（只要做一次）：**
1. **IG 切換成專業帳號**：IG App → 個人檔案 → 右上 ☰ →「帳號類型和工具」→「切換為專業帳號」→ 選「商業」（或「創作者」）。
2. **建 Meta 應用程式**：https://developers.facebook.com/apps →「建立應用程式」→ 名稱「小乖發文」→ 使用案例勾「管理 Instagram 上的訊息和內容」和「管理粉絲專頁的所有內容」（Threads 能一起勾就勾「存取 Threads API」；不能一起勾就另建一個「小乖Threads」只勾 Threads）→ 商家選「我還不想連結商家資產管理組合」→ 建立。
3. **IG 權杖**：左邊「使用案例」→ Instagram「自訂」→「使用 Instagram 登入的 API 設定」→「產生存取權杖」按「新增帳號」→ 登入 IG、允許 →「產生權杖」→ 複製（`IGAA…` 開頭）→ 在 Telegram 傳「設定 IG金鑰 那串」。
   - 按「新增帳號」出現「無法新增在應用程式所屬企業管理平台擔任角色的用戶」（IG 掛在企業管理平台底下）：改用第 5 步的 FB 權杖，先在粉專設定把 IG 連結到粉專，權限再多加 `instagram_basic`、`instagram_content_publish`、`business_management`，同一串分別傳「設定 FB金鑰 那串」和「設定 IG金鑰 那串」。
4. **Threads 權杖**：Threads 使用案例 →「自訂」→ 權限加 `threads_basic`、`threads_content_publish` →「設定」→「使用者權杖產生器」→「新增或移除 Threads 測試人員」把自己加進去，到 Threads App「設定 → 帳號 → 網站權限 → 邀請」接受 → 回到權杖產生器按「產生存取權杖」→ 複製（`THAA…` 開頭）→ 傳「設定 Threads金鑰 那串」。
5. **FB 粉專權杖**：打開「圖形 API 測試工具」https://developers.facebook.com/tools/explorer → 右邊選「小乖發文」→ 權限加 `pages_show_list`、`pages_manage_posts`、`pages_read_engagement` →「Generate Access Token」→ 選你的粉專、允許 → 複製權杖 → 到「存取權杖偵錯工具」https://developers.facebook.com/tools/debug/accesstoken 貼上按「偵錯」→ 最下面按「延長存取權杖」→ 複製新的那串 → 傳「設定 FB金鑰 那串」（有好幾個粉專會讓你選要發哪一個）。
6. **更新 Apps Script**：Code.gs 貼上新版 →「助理小乖007」→ 管理部署作業 → 鉛筆 → 新版本 → 部署。

小乖收到權杖會把那則訊息刪掉。IG、Threads 權杖 60 天到期，小乖每 7 天自動換新；FB 粉專權杖（從延長過的權杖換來的）不會過期。打「發文狀態」看目前設定了哪些。

**怎麼發：**
- **智囊軍師圖卡**：圖卡做好後按「📤 發社群」（文案就是小乖寫的貼文）。
- **剪好的 Reels**：長按小乖給的「📝 貼文文案參考」那則 →「回覆」打「發社群」，影片和文案一起發；也可以直接回覆影片打「發社群 文案…」。
- **自己的照片或影片**（Telegram）：傳的時候說明寫「發社群 文案…」。
- 預覽時打「發文文案 新的文案」可以換文案，按「❌ 不發」取消。

**注意：** IG 只收 JPG，小乖會把圖卡轉成 JPG、影片原檔暫存在雲端硬碟「小乖IG發文」（設成知道連結的人都能看，IG／Threads 才抓得到），發完就丟垃圾桶。圖片比例要在 4:5 直式到 1.91:1 橫式之間；Threads 一則最多 500 字（太長自動截短）；Telegram 的影片超過 20MB 小乖拿不到；IG 每 24 小時最多 25 則、Threads 250 則。

### 🎵 TikTok（送到草稿匣）

TikTok 只收影片（剪好的 Reels、自己的影片），送到你 TikTok 的草稿匣（收件匣通知）；你打開 TikTok 加音樂庫的歌、貼文案再按發佈。用的是 TikTok 官方 Content Posting API 的「上傳到草稿」（`video.upload`），只發你自己的帳號，用沙盒（Sandbox）就好，不用送審。圖卡、照片 TikTok 官方 API 只能從驗證過的網址抓，所以要先做下面的「圖卡設定」。

**設定（只要做一次）：**
1. 到 https://developers.tiktok.com 用你的 TikTok 帳號登入 → 右上「Manage apps」→「Connect an app」→ 名稱「小乖發文」→ 建立。
2. 左上切到 **Sandbox** →「Create Sandbox」。
3. 「Products」按「Add products」加 **Login Kit** 和 **Content Posting API**。
4. Login Kit 的 **Redirect URI**：先在 Telegram 傳「TK設定」，小乖會給你一串網址（就是小乖的 Webhook 網址），整串貼上。
5. 「Scopes」確認有 `user.info.basic`、`video.upload`。
6. 「Sandbox settings」→「Target Users」加你自己的 TikTok 帳號。
7. 回到應用程式最上面複製 **Client key**、**Client secret**，在 Telegram 傳「設定 TK金鑰 Client key Client secret」（兩串中間空一格；小乖收到會把訊息刪掉）。
8. 小乖回一個連結，打開、用 TikTok 帳號按「允許」，看到「✅ TikTok 連好了」就完成。

之後影片按「發社群」，預覽就會多一個 TikTok。TikTok 登入一年內有效，過期打「TK設定」重新連結。

**圖卡也送 TikTok（做一次）**：圖卡經過留言回覆用的 Cloudflare 中繼站轉給 TikTok。
1. Cloudflare 中繼站換成最新的 `meta-relay/worker.js`，部署。
2. TikTok for Developers → 應用程式 →「URL properties」→ 新增「URL prefix」，填中繼站網址（`https://…workers.dev/`），選下載檔案驗證。
3. 檔案裡那一行整串，貼到 Cloudflare 中繼站的變數 `TK_VERIFY`，部署後回 TikTok 按「驗證」。
4. 傳「設定 TK圖卡 中繼站網址」給小乖。之後按「✅ 全部發」，圖卡也會一起送到 TikTok 草稿匣（自動發文也會）。打「TK圖卡」看狀態，「設定 TK圖卡 關」關掉。

## 常見問題

**LINE／Telegram 上可以做什麼？** 傳「說明」看範例。傳「清除對話」會讓小乖忘掉聊天內容，待辦和筆記不受影響。也可以直接傳圖片（可以附一句說明，例如「幫我記下來」），小乖會讀出圖片內容幫你整理，要記的話會存成筆記。語音、貼圖、影片目前還不支援。LINE 和 Telegram 共用同一段聊天記憶，在 LINE 說到一半，可以到 Telegram 接著聊。

**怎麼試算金額和 PV？** 直接傳「草本產品購買明細表」或訂單圖片就會試算（看不出品項時才當一般圖片讀）。收到明細表時小乖會先列出看到的編號和顆數（看不清楚、價目表沒有的會標 ❓），讀錯可以直接打「改 255A 3顆」「刪 270」「加 260 3顆」「第二個月 加 211 3顆」改正；看明細表固定用 gpt-4o（比較準，指令碼屬性 QUOTE_MODEL 可改），一般聊天還是用 MODEL。明細表會讀兩次：讀完再對照圖片核對一次（補漏列、改錯字；指令碼屬性 QUOTE_VERIFY 設 off 可關掉）。Telegram 用「檔案」方式傳照片不會被壓縮，字比較清楚。接著會問四個問題（月數優先，2026-10-15 改）：①現金還是刷卡、②要買滿幾個月（1／2／3 個月、「照明細表」、「依PV補」）、③只有選「依PV補」才問要補到多少 PV 或金額（22萬／30萬 PV、「金額 30萬」），月數會拉長到達標、④入會方式（女生：新入會(草本）女＋入會 211、707 各 2；男生：新入會(草本）男＋入會 211、101 各 2；九號：新入會(9號）＋入會 9號兩組 1；舊會員：不加），有按鈕可以點，都回答後才算；兩個都有時照選的月數算（月數優先，2026-10-15 改），不夠目標不會自動補，報表會寫「離 22萬PV 還差多少」；只有月數選「照明細表」或沒選時，才自動把月數補到達標。明細表本身就超過目標時，照 SOP 刪減原則：先刪第三個月（最後一個月份）的產品，基本款 211、300、299A 不刪，一項一項拿掉、拿掉後仍達標才刪，報表會列出拿掉了哪些。明細表上有寫的（例如空白處寫「現金」「22萬」「男」，或各欄「服用 N 月」有填）就不再問，小乖會列出「📝 表上寫了：…」；說明欄先寫好（例如「現金 22萬 3個月 男」）也會直接算，說明欄優先於表上寫的；只寫「照明細表」等於②③都照明細表。說明欄可加「男」「刷卡」「舊會員」「22萬」；也可以直接打字「試算 211 2盒、777Q 1盒」。小乖會列出每項的數量、金額、PV 和總計。AI 只負責看出品項和數量，金額與 PV 由程式照價目表計算。第一次試算時，試算表會自動多一個「價目表」分頁，之後要改價格或加品項，直接改這個分頁就好（欄位：品項｜PV｜金額｜每盒顆數）。明細表會依「每次顆數 × 早中晚時段 × 30 天 × 服用月數 ÷ 每盒顆數」無條件進位算盒數；2711AB、777Q 滿 4 盒自動換組合價；火山甘露每月 1 盒、777Q 每月 2 盒、2711AB 每月 3 盒（至少 3 盒）、168/111/101 每月 2 盒且每 3 個月最多 4 盒；現金時 211 會先扣掉贈品 211(30) 和入會送的盒數（照 SOP「現金購買 211 可少算」）；「保養」欄另外算每月費用。明細表試算會自動加上新入會組合（預設女生：新入會(草本）女＋入會 211、707 各 2 盒；說明欄寫「男」改成男生組合＋入會 211、101；寫「舊會員」就不加）。明細表的試算結果會另外列出「買 1／2／3 個月」各要多少金額和 PV（照表上月份順序取）。說明欄可以加目標 PV（例如「試算 22萬」），小乖會把最後一個有寫顆數的月份拉長到達標為止。結果的格式和規則對齊「彥彬試算系統」的康園試算報表：現金每滿 2 萬送「贈品 211(30)」1 瓶（說明欄寫「刷卡」就不送）、距離 22 萬／30 萬 PV、預估可使用天數（2 字頭品項最高盒數 × 15 天），以及非經理／經理的預計獎金（總金額 × 級距 %，扣稅 10%）。

**試算報表圖片（Telegram）：** 在 Telegram 試算時，小乖會先傳一張「康園試算報表」樣式的圖片，再傳文字明細。圖片是用 Google 簡報畫的，另外會存一份到你雲端硬碟的「小乖試算報表」資料夾（不公開）。第一次使用前，先在 Apps Script 編輯器左側「服務」按 ＋，加入「Google Slides API」和「Drive API」（Drive 用來把報表頁面改成直式；沒加也會出圖，只是縮小放在橫式頁面）；再到函式選單選 `authorizeReport` 按「執行」，允許「簡報」和「雲端硬碟」權限。LINE 也會收到同一張圖片：LINE 只收公開網址的圖片，所以 LINE 試算的報表圖片會在雲端硬碟設成「知道連結的人都能看」（2026-10-14 使用者同意）。 2026-10-16 改成象牙白香檳金版面（使用者選 A）：標題＋日期、購買者／試算者、六欄品項表（品項｜數量｜單價｜PV｜小計金額｜小計 PV）、總金額／總 PV、22 萬／30 萬達標進度條、預計獎金，配色在 `RC`。

**要換 AI 模型？** 在指令碼屬性新增 `MODEL`，值填 `gpt-5-mini`（預設是 `gpt-4o-mini`）。

**費用？** Google 試算表與 Apps Script 免費。OpenAI 依用量計費。LINE 一般回覆訊息不計費，但提醒用的是「推播訊息」，免費方案每月有則數上限，同一時間到的提醒會合併成一則送出。

**會在哪裡收到提醒？** LINE 和 Telegram 都綁定的話，兩邊都會收到；網頁開著時也會跳提醒，所以有機會收到不只一次，屬正常現象。Telegram 的通知沒有則數限制。

**資料可以直接在試算表改嗎？** 請不要手動改「資料」那一欄，那是程式讀的內容；「摘要」欄只是方便你瀏覽。要改資料請用網頁或 LINE。

**安全性：** 同步密碼等於鑰匙，不要分享給別人。若外流，到指令碼屬性改掉 `SYNC_KEY`，再更新 LINE 的 Webhook URL、重新執行 `setupTelegram`，並更新網頁設定。要換綁帳號的話，刪掉 `OWNER_USER_ID`（LINE）或 `TG_OWNER_CHAT_ID`（Telegram）後重新傳「綁定」。

3. 其他人邀請、或主人不在那個群組、或超過 10 分鐘，小乖一進群組就馬上退出（LINE 不會告訴機器人是誰邀的，所以用這兩個條件確認）。
4. 在群組裡小乖只回主人，而且訊息開頭要打「小乖」；主人打「小乖離開」小乖就退出那個群組。私訊「群組關」小乖會離開所有群組，「群組」看目前在幾個群組。
