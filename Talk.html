🎙️ 說「嘿 小乖」就能問

做一次就好：之後不用打開網頁，直接說「嘿 小乖」，小乖聽完會念答案給你聽。需要 iOS 18 以上。

  1. 打開 捷徑 App，按右上角 ＋。
  2. 搜尋並加入 聽寫文字，語言選 中文（台灣）。
  3. 加入 URL 編碼（會自動接上「聽寫的文字」）。
  4. 加入 文字：先貼上剛剛複製的網址，再在網址最後面點一下，選上方變數 已編碼的 URL。
  5. 加入 取得 URL 內容，再加入 朗讀文字。
  6. 點最上面的名稱，改成 小乖。
  7. （連續對話，像 Siri 一樣一直聊）加入 如果：點藍色的輸入改選 URL 的內容，條件選 包含，文字填 有事再叫我。
  8. 加入 停止此捷徑，按住它拖到「如果」下面、「否則」上面。
  9. 最下面加入 執行捷徑，捷徑選 小乖，按完成。
  10. 到 設定 → 輔助使用 → 語音快捷指令，按 加入動作，選捷徑 小乖。
  11. 照畫面念三次 嘿 小乖，完成。

之後說「嘿 小乖」再講要問的事，例如「明天有什麼行程」。小乖回答完會自動再聽你說，想結束就說「結束」或「沒事了」，或不講話也會停。網址裡有你的同步密碼，請不要傳給別人。

📸 說「幫我試算」自動讀最新照片

拍好明細表（或截圖）後，直接說「幫我試算」，捷徑會自動抓手機裡最新的一張照片傳給小乖，不用選照片。報表會傳到 Telegram。

  1. 打開 捷徑 App，按 ＋，加入 取得最新的照片（數量 1，「包含螢幕截圖」打開）。
  2. 加入 調整影像大小，寬度填 1500（高度留自動）。
  3. 加入 轉換影像，格式選 JPEG。
  4. 加入 Base64 編碼。
  5. 加入 取得 URL 內容：網址貼上剛複製的網址；點「顯示更多」，方法選 POST，要求本文選 JSON，按「新增欄位 → 文字」加四個：
    action 填 ask　key 貼上密碼　ask 填 試算　image 選變數「Base64 編碼的結果」
  6. 加入 朗讀文字，名稱改成 小乖試算，按完成。
  7. 到 設定 → 輔助使用 → 語音快捷指令 → 加入動作 → 選 小乖試算，念三次 幫我試算。

也可以在「照片」App 打開明細表 → 分享 → 選 小乖試算（第 1 步改成「接收分享的影像」就能這樣用）。手機只會說一句「收到明細表」，「現金還是刷卡」這些問題會傳到 Telegram，按按鈕回答就好。

🪶 說「幫我寫文案」直接出文案和圖卡

說完選一個主題，小乖寫好文案、畫好圖卡：文案自動複製（打開 FB／IG／LINE 直接貼上），圖卡自動存到相簿。

  1. 打開 捷徑 App，按 ＋，加入 列表，填六項：軍師判定、觀念主題、健康主題、火山草本、經營主題、網路行銷。
  2. 加入 從列表中選擇。
  3. 加入 取得 URL 內容：網址貼上剛複製的網址；點「顯示更多」，方法選 POST，要求本文選 JSON，新增三個文字欄位：
    action 填 card　key 貼上密碼　ask 選變數「已選擇的項目」
  4. 加入 取得字典值，鍵填 text，再加入 拷貝到剪貼簿。
  5. 再加入 取得字典值，鍵填 img；點它藍色的輸入，改選 URL 的內容。
  6. 加入 Base64 解碼、儲存到照片圖庫、快速查看。
  7. 名稱改成 小乖寫文案，按完成。
  8. 到 設定 → 輔助使用 → 語音快捷指令 → 加入動作 → 選 小乖寫文案，念三次 幫我寫文案。

第一次執行時，捷徑會問能不能連到小乖、能不能存照片，都按「允許」。

💡 不想另外做捷徑也可以：說「嘿 小乖」，再說「寫文案」或「寫一篇火山草本的文案」，智囊軍師就會寫好，文案和圖卡傳到 Telegram（沒說主題就由軍師判定）。

⚠️ 語音口令不要用「嘿 小乖」開頭：手機一聽到「嘿 小乖」就先跑「小乖」那個捷徑，後面的「試算」「寫文案」就被吃掉了。也可以直接說「嘿 Siri，小乖寫文案」，不用另外設口令。
