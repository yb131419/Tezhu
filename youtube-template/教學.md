# YouTube 自動上傳範本：手機也能照著做的教學

這份範本會把雲端硬碟裡的影片，自動上傳到**你自己的** YouTube 頻道，並加入播放清單。標題、說明、標記來自你自己的試算表。

**先講限制（很重要）**
- 未通過 YouTube 審核的 API 專案，上傳的影片一律是**私人**。要公開，請到 YouTube Studio 手動改。
- 每 15 分鐘檢查一次，每次最多傳 4 分鐘，大檔會分段接著傳，所以一支影片可能要跑好幾個小時。
- 程式只負責上傳、加播放清單與同步標題說明標記，不包含頻道數據與分析報表。

---

## 第一步：建立試算表（用來放影片資料）

1. 打開 Google 試算表，建立一份新的試算表（名字隨意，例如「我的 YouTube 自動上傳」）。
2. 在試算表上方選單按 **擴充功能 → Apps Script**，會開啟程式編輯器。

> 一定要從試算表的「擴充功能」開啟，程式才知道要讀哪一份試算表。

## 第二步：貼上程式與權限設定

1. 編輯器左側**「專案設定」**（齒輪圖示）→ 勾選 **「在編輯器中顯示 'appsscript.json' 資訊清單」**。
2. 回到編輯器左側**「編輯器」**（程式碼圖示）。
3. 點左邊 `Code.gs`，把裡面原本的內容全部刪掉，貼上範本的 `Code.gs` 全部內容。
4. 點左邊 `appsscript.json`，把內容全部換成範本的 `appsscript.json` 內容。
5. 按上方的 **儲存** 圖示（磁碟片）。

## 第三步：設定一次（建立資料夾與分頁）

1. 在編輯器上方的函式下拉選單，選 **「一次設定」**。
2. 按 **執行**。
3. 第一次執行會跳出授權視窗：按 **審查權限** → 選你的 Google 帳號 → 如果出現「未驗證的應用程式」，按 **進階 → 前往（不安全）** → **允許**。
4. 執行完成後，你的雲端硬碟會出現「**YT自動上傳**」資料夾，試算表會多出「**影片資料**」與「**上傳紀錄**」兩個分頁。

## 第四步：在 YouTube 建立播放清單

1. 打開 YouTube Studio → 左側 **自訂內容 → 播放清單** → 建立播放清單。
2. 名稱要和程式裡的設定一樣（見第五步），例如「我的系列播放清單」。

## 第五步：修改分類設定（只改這裡）

1. 回到編輯器，在 `Code.gs` 找到最上面的 `CONFIG` 區塊。
2. 找到這一段，改成你自己的資料夾名稱與播放清單名稱：

   ```
   CATEGORIES: {
     '我的系列': { playlist: '我的系列播放清單', ai: false },
   },
   ```

   - 左邊的「我的系列」是雲端硬碟裡**分類子資料夾的名稱**。
   - `playlist` 是要加入的播放清單名稱（要和 YouTube 上一模一樣）。
   - `ai` 設成 `true` 會標註為「AI 創作（變造或合成內容）」，沒有就維持 `false`。
   - 想要多個分類，就照格式再加一行，例如 `'開箱': { playlist: '開箱播放清單', ai: false },`。
3. 按 **儲存**。

## 第六步：填寫影片資料

在試算表的「**影片資料**」分頁，每一集一列：

| A 集數 | B 標題 | C 說明 | D 標記 |
|---|---|---|---|
| EP01 | 第一集標題 | 這一集的說明文字… | 標記1 標記2 標記3 |

- **A 欄集數必須和影片檔名開頭一致**：例如 A 欄是 `EP01`，影片就要取名 `EP01_開場.mp4`（集數後面接底線或空白）。
- **B、C 欄要填**，少一格這一集就不會上傳（程式會略過）。
- D 欄標記用空白分隔，可以加 `#` 也可以不加。

## 第七步：檢查設定

1. 編輯器選 **「檢查設定」** → 按 **執行**。
2. 按左下角**「執行記錄」**（或試算表都行），看到：
   - 分類子資料夾「有」、播放清單「找到了」
   - 影片資料「幾集」
   都對，就可以往下。

## 第八步：授權 YouTube 與雲端硬碟

1. 選 **「授權」** → 按 **執行**，按「允許」。（如果第三步已經全部允許，這步會直接完成。）

## 第九步：開啟自動排程

1. 選 **「開啟每15分鐘自動上傳」** → 按 **執行**。
2. 選 **「開啟每日同步」** → 按 **執行**（之後標題、說明、標記改了，每天 9 點左右會自動更新到已上傳的影片）。

## 第十步：開始上傳

1. 打開雲端硬碟 → **YT自動上傳** → 點進對應的分類資料夾（例如「我的系列」）。
2. 把影片放進去，檔名開頭要是集數，例如 `EP01_開場.mp4`。
3. 最多等 15 分鐘，排程會自動開始上傳。成功後影片會移到分類資料夾裡的「**已上傳**」子資料夾，並寄信通知你。
4. 想立刻試：編輯器選 **「立即檢查一次」** → 執行。

## 第十一步：公開影片

上傳的影片是私人。到 YouTube Studio 找到影片 → **可見範圍** 改成「公開」，或設定排程發布。

## 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 影片一直沒上傳 | 用「檢查設定」看分類、播放清單、影片資料是否都對；檔名開頭是否和 A 欄一致。 |
| 影片被移到「失敗」資料夾 | 同一支連續失敗 3 次。看「上傳紀錄」分頁或寄來的通知，修好後把影片搬回分類資料夾。 |
| 播放清單找不到 | 名稱要和 YouTube 上完全一樣（忽略空白與「｜」「・」）。 |
| 想暫停自動上傳 | 編輯器選「關閉自動上傳」→ 執行。 |
| 每次執行都跳授權 | 把「授權」再執行一次，按允許。 |
| 時區不是台灣 | 編輯器左側「專案設定」→ 時區改成你的時區，排程時間才正確。 |

---

## 這個範本沒有包含的

- 頻道數據、觀看分析與每日報表（需要另外啟用 YouTube Analytics）。
- 公開、排程發布（需要手動在 YouTube Studio 設定）。
- 任何金鑰、ID 或通知到 LINE、Telegram 的設定（只有寄信到你自己的 Google 帳號）。
